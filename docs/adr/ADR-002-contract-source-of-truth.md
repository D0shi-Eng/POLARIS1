# ADR-002 — Contract source of truth and derivation

**Status:** ACCEPTED (Phase 00 / W2, 2026-09-01)
**Supersedes:** nothing. **Depends on:** ADR-001 (ACCEPTED — CONDITIONAL).

## Context

POLARIS needs one definition per contract, consumable later from a Rust/native core, a
TypeScript desktop surface, tests and a CLI. Three hand-written definitions of the same contract
(a TypeScript interface, a Rust struct, a JSON Schema) drift silently and are the standard way
a typed boundary rots.

## Decision

**JSON Schema 2020-12 under `contracts/schemas/` is the single hand-authored source of truth.**
Everything else is derived or guarded:

- Runtime validation: Ajv 2020 in strict mode, loading the schema files directly.
- TypeScript types: generated by `json-schema-to-typescript`, headed
  `GENERATED FILE — DO NOT EDIT MANUALLY`, byte-reproducible, and guarded by a drift test that
  regenerates in memory and compares.
- Serialization: JSON, with a canonical form (`POLARIS-CJSON-1`) for anything that must hash.
- Rules JSON Schema cannot express live in code, never restating a schema constraint:
  single-document semantics in `src/semantics.ts`, cross-document invariants in
  `src/invariants/`.
- The one unavoidable duplication — the `ErrorCode` vocabulary, needed as a TypeScript value —
  is guarded by a parity test against the schema enum.

A future Rust core consumes the same schema files; nothing in this decision is
TypeScript-specific.

## Alternatives considered

- **Protobuf / Cap'n Proto as source of truth.** Rejected: nothing in W2 needs binary framing or
  a wire-compatibility story, `oneOf`-style conditional validation is weaker there, and the
  fixtures stop being reviewable by hand. Revisit if IPC throughput ever becomes the constraint.
- **TypeScript types as source, schema generated from them.** Rejected: it makes the desktop
  language authoritative over a boundary the native core must also own.
- **Hand-writing both and reconciling by review.** Rejected outright — this is the failure mode
  the decision exists to prevent.

## Consequences

- Contract changes start in the schema. A generated file edited by hand fails the build.
- `if/then` conditionals are stripped from a throwaway staged copy before codegen because
  TypeScript cannot express them; the strip is lossless at the type level and never becomes a
  second source of truth. Cross-field rules are therefore enforced at runtime, not by the
  compiler — an accepted, documented limit.
- Adding a language means adding a generator, not a second definition.
